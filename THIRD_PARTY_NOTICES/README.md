## Lyricify Lyrics Helper

The desktop lyrics module contains a heavily rewritten and simplified Swift adaptation of the lyric search ideas and endpoint structure from Lyricify Lyrics Helper. Only the QQ Music, NetEase Cloud Music, and Apple Music lyric access paths are retained.
